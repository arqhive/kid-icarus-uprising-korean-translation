신기 목록의 정렬과 메뉴 글씨를 고치고, 대사 번역을 일본어 원문과 다시 맞춰 본 판입니다.

**원본 일본판(`0004000000030000`)용입니다. 본문 한글은 한국판 3DS 본체와 Azahar(한글 폰트 설치)에서만 나옵니다.**

## 변경 사항

- **신기 목록의 「가나다 순」 정렬이 한글 가나다순으로 동작합니다.** 지금까지는 일본어 이름 순서대로 정렬돼 한글 이름과 맞지 않았습니다.
- **장비 화면의 「신기」·「기적」 글씨 뒤에 네모난 색 판이 보이던 문제를 고쳤습니다.** 원본처럼 글자만 보입니다.
- 메인 메뉴, 공중전·지상전·장비 메뉴, 「다 함께」 전적, 배틀로열·천사 강림 글씨도 같은 문제가 생기지 않도록 원본에 맞췄습니다.
- 대사 몇 줄의 번역을 다듬었습니다. 일본어 원문과 대조해 빠지거나 덧붙은 말을 고쳤습니다.
