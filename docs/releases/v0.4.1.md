대사 번역의 일본어식 표현을 다듬은 판입니다.

**원본 일본판(`0004000000030000`)용입니다. 본문 한글은 한국판 3DS 본체와 Azahar(한글 폰트 설치)에서만 나옵니다.**

## 변경 사항

- 일본어 문장 구조를 그대로 옮겨 어색하던 대사 몇 줄을 자연스러운 한국어로 다듬었습니다. 원문의 말과 뜻은 그대로 두었습니다.

## 배포 파일

| 파일 | 설명 |
|---|---|
| `AKDJ_KPatch_v0.4.1_LayeredFS.zip` | SD 카드 루트에 푸는 LayeredFS 패치(`luma/titles/0004000000030000/`). HOME 메뉴 게임 이름·배너는 일본어 그대로입니다. |
| `AKDJ_KPatch_v0.4.1_CIA.zip` | 일본판 CIA·3DS를 끌어다 놓으면 HOME 메뉴 배너·게임 이름까지 한글인 CIA·3DS를 만드는 패처입니다. |
| `AKDJ_KPatch_v0.4.1_AzaharFont.zip` | Azahar 한글 시스템 폰트입니다. v0.2와 같으며, 이미 설치했다면 다시 받을 필요가 없습니다. |

LayeredFS를 쓰고 있었다면 `sd:/luma/titles/0004000000030000/` 폴더를 지우고 새로 복사하세요. 자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
