일본어 이름의 한글 표기를 흔히 쓰는 표기로 바꾼 판입니다.

**원본 일본판(`0004000000030000`)용입니다. 본문 한글은 한국판 3DS 본체와 Azahar(한글 폰트 설치)에서만 나옵니다.**

## 변경 사항

- 스태프롤의 일본인 제작진 이름을 흔히 쓰는 표기로 바꿨습니다(예: 다카하시 → 타카하시, 마쓰모토 → 마츠모토).
- 신기·적 이름의 표기를 바꿨습니다: 격검 가게마루 → 격검 카게마루, 쓰복 → 츠복, 도쓰코쓰 → 토츠코츠.
- 대사 몇 줄의 번역을 다듬었습니다.
