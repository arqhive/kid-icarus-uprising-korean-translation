저장소를 공개하며 배포 파일 이름을 바꾼 판입니다. **게임 안의 한글은 v0.1과 같습니다.** v0.1을 쓰고 있다면 다시 받을 필요가 없습니다.

**원본 일본판(`0004000000030000`)용입니다. 본문 한글은 한국판 3DS 본체와 Azahar(한글 폰트 설치)에서만 나옵니다.**

## 변경 사항

- 배포 파일 이름을 `AKDJ_KPatch_v0.2_…` 형식으로 바꿨습니다. 패처는 `_CIA`, LayeredFS는 `_LayeredFS`, Azahar 폰트는 `_AzaharFont`가 붙습니다.

## 배포 파일

| 파일 | 설명 |
|---|---|
| `AKDJ_KPatch_v0.2_LayeredFS.zip` | SD 카드 루트에 푸는 LayeredFS 패치(`luma/titles/0004000000030000/`). HOME 메뉴 게임 이름·배너는 일본어 그대로입니다. |
| `AKDJ_KPatch_v0.2_CIA.zip` | 일본판 CIA·3DS를 끌어다 놓으면 HOME 메뉴 배너·게임 이름까지 한글인 CIA·3DS를 만드는 패처입니다. |
| `AKDJ_KPatch_v0.2_AzaharFont.zip` | Azahar 한글 시스템 폰트입니다. Azahar로 실행할 때만 필요합니다. |

LayeredFS와 패처는 둘 중 하나만 쓰면 됩니다. 자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
