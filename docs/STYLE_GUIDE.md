# 신 광신화 파르테나의 거울 한글화 번역 지침

일본판(3DS, 0004000000030000) 텍스트를 한국어로 옮길 때 지키는 규칙.
번역을 맡는 사람(에이전트)은 작업 전에 이 문서와 `translation/GLOSSARY.md` 를 반드시 읽는다.
**번역 기준은 언제나 일본어 원문이다.** 영어판(`en`)은 뜻 확인용 참고일 뿐이다(영어판은 의역·말장난 교체가 많다).

## 작업 절차

1. 원문 묶음: `work/src/<묶음>.json` — 항목마다 `key`, `speaker`(화자, 일본어), `label`, `jp`(원문), `en`(영어판), `max_px`(한 줄 폭 한도).
2. 번역을 `translation/batches/<묶음>.json` 에 쓴다: `{"key": "번역문", ...}` (UTF-8, JSON).
   - 원문 묶음의 **모든 key** 를 넣는다.
   - 줄바꿈은 JSON 의 `\n`. 원문의 줄 수보다 늘리면 안 된다(줄이는 것은 가능).
   - `{0.2:6400}` 같은 태그는 원문에서 **그대로 복사**한다(개수·종류 같게, 위치는 한국어 어순에 맞게).
3. 검사: `python tools/tl.py check <묶음>` — **오류 0 이 될 때까지 고친다.** 경고는 가능하면 줄인다.
   - 반영(`apply`)은 하지 않는다. 다른 묶음 파일은 건드리지 않는다.

## 줄 폭

- 한글·한자·가나 한 글자 24px, 반각 공백 9px, 영문·숫자는 약 12~17px.
- 대사(스토리·잡담·게임 방법 자막): 한 줄 **504px(공중전은 552px) 이하** — 한글 약 20자. 넘으면 오류.
- 도감 설명·팁: 624px(약 25자).
- 메뉴·버튼·이름: **원문 폭(max_px) 이하가 원칙.** 원문보다 넓으면 경고, 훨씬 넓으면 오류. 버튼·목록 칸이 좁으므로 짧게.
- 줄바꿈 위치는 한국어에 맞게 옮겨도 된다. 줄 수는 원문 이하.

## 문체 규칙 (사용자 확정, 다른 작품과 공통)

- **문장이 끝나면 마침표.** 원문이 `。`를 생략해도 종결어미로 끝나면 찍는다. 메뉴 항목·명사구·고유명사에는 찍지 않는다.
  **줄임표(…)로 끝나면 마침표를 덧붙이지 않는다.** `!` `?` 로 끝나면 그대로.
- **명사형 원문은 명사형으로.** 마침표를 찍으려고 서술어를 새로 붙이지 않는다.
- **물결표 뒤에 다른 부호를 겹치지 않는다.** `~,` `~.` 금지, `~!` 허용. 물결표는 되도록 쓰지 않는다.
- **대사 속 '그녀/그들' 금지.** 이름이나 '그 애/그 녀석/그 사람'으로.
- **직역투 금지**: `이 내가`(この俺が) → `내가`, `~하는 것이다`, `~해 버렸다` 남발, `~하고 있다` 남발, `~에 대해`,
  `4개의 X` → `X 4개`, `이것을/그것을` → `이걸/그걸`, 끊긴 문장은 종결어미나 말줄임표로 마무리.
- 외래어는 **국립국어원 외래어 표기법**(대미지, 메시지, 타깃, 보너스 …).
- 띄어쓰기는 한국어 규범대로 반각 공백. 원문 전각 공백(`　`)은 대사에서 옮기지 않는다.
- 원문 `⋯⋯` → `……`(말줄임표 두 개), `⋯` → `…`. `“ ”` 인용은 한국어 따옴표 `“ ”` 그대로 써도 된다.
- 느낌표·물음표 겹침(`!!`, `!?`)은 원문대로 둔다.
- **한글은 KS X 1001 완성형 2,350자만** 쓸 수 있다(폰트 제한). 검사 도구가 잡는다(`똠`, `햏` 같은 글자는 다른 말로).

## 이 게임의 특징

- 대사 대부분이 **전투 중 음성과 함께 나오는 자막**이다. 짧고 입말답게. 원문보다 길게 늘이지 않는다.
- 메타 발언·말장난이 많다(예: 하데스가 "닌텐도 캐릭터 중 역대 최강" 운운). 뜻을 살리되, 일본어 말장난은 한국어로 자연스러운
  말장난이나 같은 뉘앙스의 표현으로 바꿔도 된다. 바꾼 곳은 보고에 적는다.
- 대사 화자(`speaker`)는 초상화 코드로 판정한 것이다. `パルテナもどき` 는 가짜 파르테나.

## 말투 (사용자 확정)

- **반말·존댓말은 원문의 높낮이를 그대로 따른다.** 인물별로 정해 두지 않는다. 같은 인물도 상대·상황에 따라 원문이
  です・ます면 존댓말, 반말이면 반말로 옮긴다(예: 피트가 파르테나에게 반말로 말하는 원문이면 반말).
- 원문의 말투 특징(노인 말투 〜じゃ, 예스러운 わらわ・そなた, 〜デス 말버릇, 거친 말투, 영어 섞기)은 한국어로 살린다.
  참고: 나츄레 わらわ → `이 몸`, そなた → `그대` / 딘토스·포세이돈 ワシ → `나`(このワシ → `이 늙은이`) /
  타나토스 〜デス 말버릇은 `~데스` 로 살림 / 라즈의 영어 감탄사(HAHAHA, ノー・プロブレム)는 그대로 로마자 또는 음차.
- `〜さま` → `님`(파르테나さま → **파르테나 님**), `〜くん` → `군`, `〜ちゃん` → `양`(여성)·`군`(남성) 또는 생략.
- 1인칭은 원문 높낮이에 맞춰 `저/나`. 시스템 문구는 해요체(“~하세요.”, “~할까요?”, “~했습니다.”).

## 끝나면 보고할 것

- 새로 정한 용어(용어집에 없던 고유명사) 목록
- 판단이 애매했던 곳(말장난 교체, 뜻이 불분명한 원문 등) key 와 함께
