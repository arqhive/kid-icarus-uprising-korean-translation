신 광신화 파르테나의 거울 (3DS) 한글 패치 v0.4.6
제작: arqhive

「新・光神話 パルテナの鏡」(닌텐도 3DS, 일본판) 비공식 한국어 팬 패치입니다.
배포 파일은 세 가지입니다. 게임 내 한글은 LayeredFS와 패처가 같으니 둘 중 하나만 고르면 됩니다.

- AKDJ_KPatch_v0.4.6_LayeredFS.zip (방법 A)
  설치된 일본판은 그대로 두고, Luma3DS의 게임 패치(LayeredFS)나 에뮬레이터의 모드 폴더로 덮어씌웁니다.
  좋은 점: 파일 복사로 끝나고, 키 파일이 필요 없고, 폴더만 지우면 원래대로 돌아갑니다.
  아쉬운 점: HOME 메뉴의 게임 이름과 배너는 일본어로 남고, Luma3DS 게임 패치를 켜 둬야 합니다.
- AKDJ_KPatch_v0.4.6_CIA.zip (방법 B)
  가지고 있는 일본판 CIA나 3DS 파일을 한글판으로 새로 만듭니다.
  좋은 점: HOME 메뉴 배너·게임 이름까지 한글이고, 만든 파일을 에뮬레이터에서 바로 실행할 수 있습니다.
  아쉬운 점: 일본판 CIA 또는 3DS 파일 하나와 윈도우 PC가 필요하고, 암호화된 원본이면 boot9.bin이 필요합니다.
             되돌리려면 원본 CIA를 다시 설치해야 합니다.
- AKDJ_KPatch_v0.4.6_AzaharFont.zip
  에뮬레이터 Azahar에서 한글을 보기 위한 시스템 폰트입니다. Azahar를 쓸 때만 필요합니다.


[중요: 한국판 3DS 본체에서만 한글이 나옵니다]

이 게임은 대사와 메뉴 글자를 본체에 내장된 시스템 폰트로 그립니다.
한국판 3DS 본체의 시스템 폰트에는 한글이 있어서 한글이 그대로 나오지만,
일본판·북미판·유럽판 본체의 시스템 폰트에는 한글이 없어 글자가 나오지 않습니다.
에뮬레이터 Azahar에서는 함께 배포하는 AzaharFont를 설치하면 한글이 나옵니다.


[준비물]

- 일본판 「新・光神話 パルテナの鏡」(타이틀 ID 0004000000030000).
  북미판·유럽판(Kid Icarus: Uprising)에는 적용할 수 없습니다.
- 3DS 실기: 한국판 본체, Luma3DS가 설치된 본체와 SD 카드.
- 에뮬레이터: Azahar.


[방법 A. LayeredFS: 3DS 실기 (Luma3DS)]

1. AKDJ_KPatch_v0.4.6_LayeredFS.zip 안의 luma 폴더를 SD 카드 루트에 그대로 복사합니다.
   다음과 같이 파일이 놓이면 됩니다.

     sd:/luma/titles/0004000000030000/romfs/jp/...

2. 본체를 켤 때 SELECT를 누른 채로 두면 Luma3DS 설정 화면이 나옵니다.
   "Enable game patching"을 켜고 저장합니다.
3. 게임을 실행합니다.

- 예전에 다른 패치를 넣은 적이 있다면 sd:/luma/titles/0004000000030000/ 폴더를 지운 뒤 새로 복사하세요.


[방법 A. LayeredFS: Azahar]

1. 아래 [Azahar 한글 폰트]를 먼저 설치합니다.
2. 게임 목록에서 신 광신화 파르테나의 거울을 오른쪽 클릭하고 "Open" → "Mods Location"을 누릅니다.
3. 열린 폴더(…/load/mods/0004000000030000/)에 ZIP 안의
   luma/titles/0004000000030000/romfs 폴더를 통째로 복사합니다.

     …/load/mods/0004000000030000/romfs/jp/...

4. 게임을 실행합니다.


[방법 B. 패처: 한글판 CIA / 3DS 만들기]

1. 쓰려는 곳에 맞는 일본판 파일 하나를 준비합니다.
   3DS 실기에 설치하려면 .cia, 에뮬레이터나 플래시카트에서 쓰려면 .3ds 파일입니다.
   결과는 넣은 파일과 같은 형식으로 나옵니다.
2. AKDJ_KPatch_v0.4.6_CIA.zip 을 폴더째 압축 풀고, 준비한 파일을 "패치하기.bat"에 끌어다 놓습니다.
3. 원본과 같은 폴더에 "원래 이름_KO.cia" 또는 "원래 이름_KO.3ds"가 생깁니다. 원본 파일은 바뀌지 않습니다.
4. 3DS 실기: 만든 CIA를 FBI 등으로 설치합니다. 이미 설치된 일본판에 덮어 설치해도 세이브는 유지됩니다.
   이렇게 설치했다면 SD 카드의 LayeredFS 폴더(luma/titles/0004000000030000)는 필요 없습니다.
5. Azahar: 아래 [Azahar 한글 폰트]를 설치한 뒤 만든 파일을 실행합니다.

- 원본 파일이 암호화되어 있으면 boot9.bin이 필요합니다.
  본체에서 GodMode9으로 덤프한 파일을 "패치하기.bat"과 같은 폴더에 두세요.
  Azahar(또는 Citra)의 sysdata 폴더에 이미 있으면 따로 둘 필요가 없습니다.
- 이미 복호화된 파일(Decrypted)은 키 없이도 됩니다.
- 만들어진 3DS 파일은 복호화된 상태라 에뮬레이터·플래시카트용입니다. 3DS 본체에는 CIA를 설치하세요.
- 작업하는 동안 약 5GB의 여유 공간이 필요합니다.
- 이미 패치한 파일이나 다른 판(북미판·유럽판)을 넣으면 확인 단계에서 멈춥니다.


[Azahar 한글 폰트]

AKDJ_KPatch_v0.4.6_AzaharFont.zip 안의 nand 폴더를 Azahar 사용자 폴더에 그대로 복사합니다.
Azahar 사용자 폴더는 Azahar 메뉴 File → Open Azahar Folder로 열 수 있습니다(보통 %APPDATA%\Azahar).

     …/Azahar/nand/00000000000000000000000000000000/title/0004009b/00014002/content/00000000.app

- 이 폰트는 Azahar가 내장한 대체 폰트에 한글 2,350자를 더한 것입니다. Azahar로 실행하는 모든 게임에 적용됩니다.
  한자는 이 게임에 나오는 것과 JIS 1수준만 남겨서, 다른 일본어 게임에서 드문 한자가 빠질 수 있습니다.
- 본체에서 덤프한 시스템 폰트를 이미 이 위치에 넣어 두었다면 덮어쓰기 전에 백업해 두세요.
  원래대로 돌리려면 00014002 폴더를 지우면 됩니다.


[알려진 문제]

- 일본판·북미판·유럽판 3DS 본체에서는 한글이 나오지 않습니다(위 [중요] 참고).
- 게임 방법·광고 영상 속 화면 글자는 일본어 그대로입니다. 영상 위에 뜨는 자막은 한글입니다.
- 음성은 일본어 그대로입니다.
- 가짜 파르테나의 이마에 쓰인 「オレ」(3D 모델 그림)는 일본어 그대로입니다.
